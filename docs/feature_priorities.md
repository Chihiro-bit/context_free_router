# 功能优先级

| 功能 | 描述 | 优先级 |
| --- | --- | --- |
| 路由注册 | 集中式路由表配置，支持命名路由 | P0 |
| 无 Context 跳转 | 全局直接调用 `LightRouter.to('/path')` | P0 |
| 参数传递 | 支持 URL 参数（如 `/detail?id=1`）和对象参数 | P1 |
| 路由栈操作 | 支持 `back()`、`off()`（替换当前页）与 `offAll()`（清空栈） | P0 |
| 路由守卫 | 全局或单路由拦截器，可实现认证等场景 | P1 |
| 生命周期绑定 | 路由销毁时自动释放相关资源（控制器/流） | P1 |
| 基础动画 | 内置 5 种过渡动画（fade/slide/cupertino 等） | P2 |
